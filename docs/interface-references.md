# Interface references

Reviewed for SignalShade's operator layout on October 14, 2026. These are workflow and layout references, not dependencies or claims of compatible device control.

- [Blackmagic ATEM Software Control](https://www.blackmagicdesign.com/products/atemconstellation8k/softwarecontrol): separates major functions into pages and provides camera CCU/color-correction controls. Useful reference for keeping the current adjustment task prominent.
- [Pomfort Livegrade main screen](https://kb.pomfort.com/livegrade/reference/main-screen/main-screen-overview/): distinguishes its toolbar, camera slots, grading controls, and metadata/settings panels. Useful reference for separating signal adjustment from connection/configuration detail.
- [SKAARHOJ Reactor home screen](https://docs.skaarhoj.com/2_basics/homescreen.html): device connections and panel configuration have their own setup areas. Useful reference for keeping network setup out of each channel's control surface.

SignalShade applies these ideas with a compact connection/status header, a single channel toolbar, larger channel tiles, and section/family tabs. Setup, ordering, help, and diagnostics stay behind explicit controls; live adjustment and target identity stay visible. Connection problems, write locks, and save errors remain visible when actionable.
